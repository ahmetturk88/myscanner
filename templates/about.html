Why we exist

Most scanners give you a color. We give you the reasons.

A green tick that hides a failed check is worse than no answer. MyScanner is built on three rules we never break.

RULE 01

Show the evidence

Every verdict lists the checks behind it, the sources that answered and the ones that did not.

RULE 02

Unknown is not safe

If a check cannot run, the report says so. A missing answer is never turned into a clean result.

RULE 03

Confirm before you accuse

Local heuristics can only ask for review. “Malicious” needs a reputation source that confirms it.

How a scan works

From a pasted link to a report you can defend.

1. You submit

A link, file, address or domain. We validate it and refuse private-network targets up front.

2. Isolated collection

Workers fetch evidence from a filtered network that cannot reach internal systems.

3. Cross-checking

Findings are compared with reputation feeds such as URLhaus, MalwareBazaar and phishing databases.

4. Evidence report

You get the verdict, the reasons, the coverage gaps and a page preview, all private to your account.

Security by design

We scan the dangerous parts of the internet. So we built a cage first.

A security tool that can be turned against its own users is a liability. These protections run under every scan today.

  • Network isolationScanners run behind gateways that block private, loopback and cloud-metadata addresses.
  • Nothing is executedFiles get static inspection only; pages are rendered in a separate, isolated browser.
  • Your reports stay yoursResults and previews are served only to the account that ran the scan.
  • No silent sharingOptional third-party checks are off until you choose them, and each one is named.
